# Vertical grid

The vertical grid, `vgrid.in`. [`SCHISMGrid.vgrid`][rompy_schism.grid.SCHISMGrid.vgrid] takes a file, a [`VgridGenerator`][rompy_schism.grid.VgridGenerator] or a [`VGrid`][rompy_schism.vgrid.VGrid]; without one, the model is 2D.

::: rompy_schism.grid.VgridGenerator
    options:
      heading_level: 2

::: rompy_schism.vgrid.VGrid
    options:
      heading_level: 2

::: rompy_schism.vgrid.create_2d_vgrid
    options:
      heading_level: 2
