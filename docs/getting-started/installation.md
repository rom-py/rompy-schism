# Installation

You need two things: the rompy-schism Python package, which writes SCHISM workspaces, and SCHISM itself, which runs them.

## rompy-schism

rompy-schism needs Python 3.10 or later. It installs [rompy](https://rom-py.github.io/rompy/), [pylib](https://github.com/wzhengui/pylibs) (SCHISM's Python library, which reads and writes meshes), [pyTMD](https://pytmd.readthedocs.io) (tidal constituents) and its other dependencies.

```bash
pip install rompy-schism
```

These docs describe the development version on the `main` branch, which has fixes and features not yet released. To install it from GitHub:

```bash
pip install "rompy-schism @ git+https://github.com/rom-py/rompy-schism.git"
```

### Optional extras

| Extra | Adds | Needed for |
|---|---|---|
| `docs` | [rompy-docs](https://github.com/rom-py/rompy-docs) | Building these docs |
| `test` | pytest and test tools | Running the tests |
| `dev` | pytest, ruff, mypy, coverage | Development |

## SCHISM

rompy-schism writes SCHISM's input files but does not include SCHISM. There are two ways to run it.

### Docker (recommended)

The public image `ghcr.io/rom-py/schism` contains SCHISM built with MPI and NetCDF. You only need [Docker](https://docs.docker.com/get-docker/).

| Tag | Contents |
|---|---|
| `5.13.0` | SCHISM release v5.13.0 |
| `latest` | The newest release |

| Command | What runs |
|---|---|
| `schism` | Hydrodynamics |
| `schism_wwm` | Hydrodynamics coupled with the WWM wave model |
| `combine_hotstart7` | Merges the hotstart files that SCHISM writes per process into one `hotstart.nc` |

Pin a version tag for reproducible runs, since `latest` moves when a new release is published. Every image is tested with workspaces generated by rompy-schism before it is published. [Running SCHISM](../user-guide/running.md) shows how to use it.

### Your own SCHISM

Compile SCHISM from [its source](https://github.com/schism-dev/schism) with the modules you need, following the [compilation guide](https://schism-dev.github.io/schism/master/getting-started/compilation.html). The executable's name depends on how it was built, for example `pschism_TVD-VL`. Use the [`schema_version`](../user-guide/configuration.md#schism-versions) that matches the SCHISM version you build.

## Check the installation

```python exec="on" source="above" result="text"
import rompy
import rompy_schism

print(f"rompy {rompy.__version__}, rompy-schism {rompy_schism.__version__}")
```
